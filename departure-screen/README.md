# Departure screen

A gift for a train fanatic friend.

## Description

I forgot to take a photo of this before giving it away but it was super cool!

It's a small railway departure board for a train station local to her home.
It works by using the Realtime Trains API to display the next two trains and their scheduled time of departure.

I wrote this twice, once in python for a standard pi and once in micropython for a pico.

There is a rough 3d printed case so it's not all just hanging out in the open.
